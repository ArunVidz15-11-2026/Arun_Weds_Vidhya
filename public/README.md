# Assets needed here

Add these 4 files to this `public/` folder (they are referenced by the app but not included):

| File            | Purpose                                   |
|-----------------|--------------------------------------------|
| `couple.jpg`    | Hero slide background photo                |
| `couple2.jpg`   | Countdown slide background photo           |
| `envelope.png`  | Tap-to-open envelope design (from Canva)   |
| `music.mp3`     | Background music, starts after envelope opens |

Just drag and drop the files into this folder, or copy them from a terminal, e.g.:

```powershell
Copy-Item "C:\path\to\your-photo.jpg" -Destination ".\public\couple.jpg"
```
